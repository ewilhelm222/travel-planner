### Cloudflare-aware app-content comparison

The initial attempt was rolled back because a raw HTTP-to-source comparison included Cloudflare's dynamic challenge script. That comparison was invalid for this host; version 23 also received the injection. The owner explicitly replaced it with an app-owned content comparison.

The adopted check is specified in [deployment verification](../deployment-verification.md). It removes only a complete script element containing **both** `/cdn-cgi/challenge-platform/` and `__CF$cv$params`, preserving all other bytes and script elements. It then compares the remaining HTML byte-for-byte with pinned public/view.html and, for this release, version 23's unchanged source. It separately checks HTTP status and CSP. Asset SHA-256 hashes, JavaScript MIME types and API access checks remain independent requirements. Arbitrary new scripts or markup are not normalized away.

After redeployment: one Cloudflare script was removed; all remaining guest HTML bytes matched both version 23 and the pinned version 24 source. CSP passed. All six published asset hashes matched, sw.js contained v50, and all signed-out API checks passed again. No actual app regression was found; version 24 remains live.
