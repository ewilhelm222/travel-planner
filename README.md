# Travel Planner

A private, collaborative travel planner for trips with family and friends. Plan stays, connecting journeys, and daily activities through a shared board and maps, with views for different travelers.

## Status

Discovery and architecture discussion are documented. ChatGPT Sites is the selected starting platform; application implementation and deployment have not started.

## Project plan

See [the product brief, architecture, and implementation plan](docs/plan.md) for confirmed requirements, proposed behavior, open decisions, and acceptance criteria.

The next milestone is a small platform feasibility check covering private external access, shared persistence, and offline reopening on a phone. It precedes the full planner build.
